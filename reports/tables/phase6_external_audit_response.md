# Phase 6 External-Audit Response

## Prior independent reviews

Sessions 012 and 013 were inspected before Phase 6. Both remained suspended for inactivity with PRs #11 and #12 open. Their report contents were already byte-identical to the reviewed local copies, so no external branch content was imported and no session was treated as scientific authority.

## How the audit was answered

The audit's central objection was accepted rather than defended: the static asset-prior baseline beats the historical Transformer. Phase 6 then separated purge remediation, observed-session remediation, identity dependence, temporal-order dependence, within-asset ranking, event dependence, target comparability, macro provenance and market-dynamics inference.

The resulting answer is stronger and more negative than the v4 position. The corrected Transformer has pair-weighted within-asset ROC-AUC 0.4982; order destruction leaves pooled ROC-AUC essentially unchanged; the static asset prior remains stronger on proper metrics. The project can therefore claim a rigorous falsification of pooled-score interpretation, not Transformer superiority.

Five independent technical reviews covered protocol, statistics, target validity, code paths and examiner risk. Consequential conclusions were verified against local code, data and predictions.

No external recommendation was accepted without local verification against code, data and predictions.
